## 🚀 Featured Projects

### 1. ImmuTrack — Child Vaccination Management & Analytics System

A Django web application designed to support vaccination tracking and analytics.

- Provides role-based portals for parents, health workers, and administrators.
- Records vaccination doses and adverse events following immunization (AEFI), and generates PDF vaccination certificates.
- Includes an automated vaccination scheduling engine based on India's Universal Immunization Programme (UIP) guidelines, with upcoming and overdue dose reminders.
- Uses a Random Forest model to identify children at risk of missing vaccinations.
- Includes a Chart.js dashboard for vaccination coverage and clinic KPIs.

**Tech stack:** Python, Django, Scikit-learn, Pandas, ReportLab, Chart.js

🔗 [View ImmuTrack on GitHub](https://github.com/atharvagadakh2511/ImmuTrack) · [Open Live Demo](https://immutrack-nashik.onrender.com)

### 2. Customer Churn Prediction

A machine learning project focused on identifying customers who may be likely to leave a service.
